# Enterprise Wine — CodeWeavers

Marketing site for **Enterprise Wine** — running Windows Server workloads on Linux
without rewrites, recompilation, or source changes.

**Live:** https://enterprise-wine.vercel.app

Built with Next.js 16, React 19, Tailwind CSS 4 and Recharts. Includes an interactive
cost model, the engagement-model walkthrough, proof points and an FAQ.

## Develop

```bash
npm install
npm run dev
```

Open http://localhost:3000.

## Build

```bash
npm run build
```
